#### `app/api/` — API Routes

| Route | Method | Purpose |
|-------|--------|---------|
| `/api/analyze` | POST | **Core AI pipeline.** Downloads file from Supabase Storage → Vision OCR (images only) → Gemini analysis (small PDF inline, large PDF via File API) → structured JSON parse → save to `policy_analyses` table. Full fallback analysis object on Gemini error. |
| `/api/chat` | POST | **AI chatbot.** Builds user context from profile + analyzed policies → intent detection (wants recommendations?) → optionally calls `/api/recommend` → sends to Gemini chat with history → strips JSON blocks from response → returns clean text + recommendation objects. |
| `/api/recommend` | POST | **ML + AI recommendations.** Fetches profile → builds ML profile → calls Flask `localhost:5001/recommend` → enriches with Gemini (personalizes "why recommended") → saves to `policy_recommendations` → returns ranked list. |
| `/api/test-connection` | GET | Debug-only. Checks all env vars, runs a Supabase DB query. Returns JSON health status. |
| `/api/auth/` | — | **Empty directory** — no route.ts file. Likely a placeholder. |
| `/api/upload/` | — | **Empty directory** — upload happens client-side via Supabase SDK. This dir is misleading. |

#### `app/auth/callback/route.ts`

Exchanges Supabase auth code for session cookie. Handles password recovery type redirect → `/update-password`. Redirects to `/dashboard` on success.

## 🚀 DATA FLOWS

```
LOGIN:
User → /login → signIn() server action → Supabase Auth → Set session cookie → /dashboard

UPLOAD + ANALYZE:
FileDropzone → UploadContainer → Supabase Storage (policy-documents bucket)
  → POST /api/analyze
    → Google Vision OCR (images only, if GOOGLE_VISION_API_KEY set)
    → Gemini (small PDF inline, large PDF via File API)
    → JSON parse → policy_analyses table
  → UploadSuccess

CHATBOT:
ChatInput → useChatStore.sendMessage() → POST /api/chat
  → (if recommendation intent detected) → POST /api/recommend
      → Flask ML /recommend → RF + GB models → top 5 Indian policies
      → Gemini personalization
  → Gemini chat (with user context + policy data)
  → Strip JSON blocks → clean response text + recommendation cards

ML PIPELINE:
User profile → /api/recommend → Flask localhost:5001/recommend
  → StandardScaler → RF predict charge → score 10 policies → rank
  → Return top N → Gemini enriches with personalized "why recommended"
  → Save to policy_recommendations → Return to frontend
```
